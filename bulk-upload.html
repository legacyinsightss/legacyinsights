📦 Bulk Stock Upload

Upload an Excel (.xlsx, .xls) or CSV (.csv) file with the standard inventory headers below.

📋 Supported Table Headers:
  • Product Name (Required): Name of the item
  • Category: e.g. Building Materials, Plumbing, Tools, Electrical
  • Cost: Purchase / cost price (e.g. 85.00)
  • Markup: Profit percentage (e.g. 25%)
  • Price (Required): Selling price (e.g. 110.00)
  • Current Stock: Quantity on hand to add (e.g. 100)
  • Reorder Level: Low stock threshold alert (e.g. 15)
✨ Barcodes are automatically generated by the system for all uploaded items!
